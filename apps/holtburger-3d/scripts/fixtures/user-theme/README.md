# Original theme fixture

The CSS, SVG, and synthetic fonts are original diagnostic assets distributed under
this repository's AGPL-3.0-only license. `generate-fonts.py` is the complete font
source, using fontTools to construct a rectangle for A with advances of 500 and
900 units. No glyphs or font data come from a third-party font. Both TTF files are
checked in; running the probe needs no fontTools installation or system fonts.
