# Holtburger Standard theme — retired implementation plan

The original theme implementation and visual direction have been superseded by
CSS stylesheet loading. Holtburger Standard is the bundled default theme; it has
no fixed aesthetic contract.

See the [UI style guide](../../apps/holtburger-3d/UI_STYLE_GUIDE.md) for current
ownership, authoring, and verification guidance. Edit
[`holtburger-standard.css`](../../apps/holtburger-3d/src/app/themes/holtburger-standard.css)
to change the default appearance.
