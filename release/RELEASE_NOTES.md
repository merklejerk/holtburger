Holtburger beta includes the 3D client and the terminal client (CLI).

## In this beta

- The 3D client opens a server launcher where you can connect and save profiles.
- Windows setup and a macOS DMG are available alongside portable downloads.
- The CLI download includes game data, scripts, and archive conversion tools.

## Known issues

- Windows and macOS may warn when opening the app because it is not signed by a
  verified publisher. The installation guides below explain how to open it.
- CLI movement is simplified: jumping, falling, gravity, and stairs are not
  simulated locally. The server may correct your position or reject actions.

## Updating

Quit Holtburger before installing an update. Saved profiles and settings are retained.
Beta and nightly builds share the same installation and settings; installing either
replaces the other.
