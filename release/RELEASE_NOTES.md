Holtburger beta includes the 3D client and the terminal client (CLI).

## In this beta

- **3D client, runtime console:** A themed in-game console, toggled with F9 by default, shows recent client messages and can be rebound in the key bindings settings.
- **3D client, stability:** A creature or object that fails to load while you are in the world now logs a warning to the console instead of raising an error.
- **3D client, effects:** Rain and other particle effects that use solid-colour meshes now draw reliably.
- **3D client, chat:** Text selection in chat now works through shared selection handling.

## Known issues

- Windows and macOS may warn when opening the app because it is not signed by a verified publisher. The installation guides below explain how to open it.
- Borderless window sizing is best effort and may not match the requested size exactly.
- The runtime console keeps only the most recent messages, and its history is cleared when the client restarts.

## Updating

Quit Holtburger before installing an update. Beta and nightly builds share the same installation; installing either replaces the other. If F9 conflicts with a key you already use, rebind the console in the key bindings settings.
