Holtburger beta includes the 3D client and the terminal client (CLI).

## In this beta

- **3D client, World Explorer:** The World Explorer is substantially expanded, with an in-world transform gizmo, right-click entity inspection, entity possession, and refreshed navigation, scene, visuals and world map windows.
- **3D client, launcher:** The launcher now includes an Explorer view and a reorganized app settings dialog.
- **3D client, HUD:** HUD windows, settings controls, and the loading and pregame screens are unified across the launcher, game, and Explorer.
- **3D client, content:** The ACE-World weenie catalog is now bundled with 3D releases, so Explorer entity spawning has its catalog without a separate download.
- **3D client, visuals:** Palette-based appearance changes on equipment and characters now match the correct base colors.

## Known issues

- Windows and macOS may warn when opening the app because it is not signed by a verified publisher. The installation guides below explain how to open it.
- Borderless window sizing is best effort and may not match the requested size exactly.
- The runtime console keeps only the most recent messages, and its history is cleared when the client restarts.

## Updating

Quit Holtburger before installing an update. Beta and nightly builds share the same installation, so installing either replaces the other. No other action is needed for this release.
