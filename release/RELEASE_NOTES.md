Holtburger beta includes the 3D client and the terminal client (CLI).

## In this beta

- **3D client and CLI, release notes:** Release notes shown with updates now reflect edits made to the published notes.

## Known issues

- Windows and macOS may warn when opening the app because it is not signed by a verified publisher. The installation guides below explain how to open it.
- Borderless window sizing is best effort and may not match the requested size exactly.

## Updating

Quit Holtburger before installing an update. Beta and nightly builds share the same installation; installing either replaces the other. No other action is required for this release.
