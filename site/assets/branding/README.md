# Site branding

The [copper wordmark](wordmark.webp) is the approved illustrated site title,
generated with imagegen using the historical artwork mood board. Its transparent
background lets the header's parchment show through. Preserve its lettering and
copper highlights.

The site uses a 1200 × 400 transparent WebP at quality 85. The full-resolution
original lives in the [media repository](https://github.com/merklejerk/holtburger-media/blob/main/branding/wordmark-source-v1.png)
as `branding/wordmark-source-v1.png`.
Export directly from that original when changing the web asset; avoid recompressing
the WebP.

Asset preparation copies it to the generated `static/assets/branding/` directory.
The portal emblem and favicon remain shared assets in the repository-root
`assets/branding/` directory.
