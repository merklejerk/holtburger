# Website display font

Charm Bold supplies the website's display headings. The masthead uses illustrated
wordmark artwork. Body text remains
Gelasio, with Arimo for compact navigation and reference tables. The website font
does not change the client font choices.

`charm/Charm-Bold.ttf` and its adjacent `OFL.txt` are unmodified files
from the [Google Fonts repository](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/charm)
at revision `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`. The font's SHA-256 is
`6e1fa92fda7ab74fcce8ed5d7a9de10a0fb43d777590e8ef9f6931da6e932481`.

The SIL Open Font License 1.1 applies to this font rather than the application's
AGPL license. Asset preparation copies the complete font directory and license
into the published `assets/fonts/charm/` directory. Loading is local; no font
service or host-installed copy is required. Display headings use the font's
actual bold face without synthesized styles.
