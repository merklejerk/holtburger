## Learn the controls first

Start with [your first session](/holtburger/start/first-session/). Tap to cycle, hold to acquire an immediate target, then interact or attack deliberately.

The default bindings differ from retail. Rebind them in **Settings → Input**; there is no retail preset to import.

## What is built in?

| Your task                            | Holtburger 3D                                                   |
| ------------------------------------ | --------------------------------------------------------------- |
| Keep track of targets                | Bold selection outline and a separate active combat reticle     |
| Reposition during a fight            | Run-casting and archery with normal movement controls           |
| Navigate terrain and dungeons        | Detailed minimap with buildings, elevation and impassable areas |
| Reach a destination                  | Waypoints with direction and distance on the minimap            |
| Change equipment together            | Selected-slot loadouts on action bars                           |
| Find a spell                         | Name search and filters, then cast or bind it                   |
| Notice a particular creature or item | Nearby lists and name-pattern alerts                            |
| Fit the interface to your screen     | Movable HUD, UI/text scaling and themes                         |

These tools are built into the client. Existing Decal plugins and profiles cannot be imported.

## What about macros?

The [terminal client](/holtburger/tui/) includes scripting and bundled fighter/mage automation. Trade and buff services need scripts tailored to those tasks.

h3d prioritizes active play. It has no plugin system yet; scripting and plugins are future direction.

## What will feel different?

The controls and layout favor quick target changes and keeping useful actions close. Physics and rendering also differ, so take a few minutes to get a feel for movement.
