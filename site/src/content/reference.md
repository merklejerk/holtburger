## 3D controls

The [selection and interaction guide](/holtburger/3d/selection-interaction/) includes first-session defaults. Change keys and mouse preferences under **Settings → Input**.

## 3D chat commands

Use `/help` for the command list and `/help <command>` for details. Commands accept `/` or `@`.

Examples include `/waypoint`, `/corpse`, `/consent`, recall commands and messaging. Commands are not limited to chat delivery.

## TUI chat commands

Use `/help` or `/?`, then `/help <command>` for topic-specific guidance. Script lifecycle uses `/scripts`, `/run <name>`, `/script <message>` and `/unrun`.

Check help in the client you’re using; commands and options can differ.
