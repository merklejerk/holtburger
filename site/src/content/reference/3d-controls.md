## Movement and camera

| Action                           | Default                                                  |
| -------------------------------- | -------------------------------------------------------- |
| Forward / backward               | W / S                                                    |
| Turn left / right                | A / D                                                    |
| Strafe left / right              | Z / C                                                    |
| Walk                             | Hold Shift                                               |
| Toggle autorun                   | Q                                                        |
| Charged jump                     | Hold and release Space                                   |
| Enter precise jump mode          | Ctrl+Space                                               |
| Raise / lower precise jump power | W / S while aiming                                       |
| Adjust precise jump power        | Shift+scroll or the power bar                            |
| Launch precise jump              | Click the aimed jump                                     |
| Orbit camera                     | Left-drag                                                |
| Turn character and tilt camera   | Hold right button, with mouse movement enabled           |
| Move forward with mouse          | Hold middle or both buttons, with mouse movement enabled |
| Zoom                             | Scroll                                                   |

See [movement](/holtburger/3d/movement-camera/) and [jumping](/holtburger/3d/movement-camera/) for the full workflows.

## Select and interact

| Action                                     | Default                          |
| ------------------------------------------ | -------------------------------- |
| Cycle smart combat targets                 | Tap Tab / Shift+Tab              |
| Acquire immediate target                   | Hold Tab or Shift+Tab            |
| Cycle world objects                        | Ctrl+Tab / Ctrl+Shift+Tab        |
| Cycle unopened corpses                     | V / Shift+V                      |
| Select self                                | X                                |
| Interact with selection                    | R                                |
| Examine                                    | E or right-click the object/item |
| Give selected item to remembered recipient | G                                |
| Split selected stack                       | Y                                |

Start with [Smart Tab](/holtburger/3d/combat/) for everyday targeting.

## Combat and bars

| Action                                    | Default                                        |
| ----------------------------------------- | ---------------------------------------------- |
| Toggle peace/combat                       | Backquote (`)                                  |
| Combat power/accuracy presets             | 1–5 while physical combat controls are active  |
| High / medium / low attack height         | Shift+1 / Shift+2 / Shift+3 in physical combat |
| Choose spell tab                          | Shift+1 through Shift+0 in magic               |
| Cast a spell-bar cell                     | 1–0 in magic                                   |
| Wielded-caster spell                      | Ctrl+Shift+1                                   |
| Focus action bar                          | Ctrl+1 through Ctrl+0                          |
| Activate focused action-bar cell          | 1–0                                            |
| Navigate / activate a focused action cell | Arrows / Enter                                 |

Number-key actions depend on the current controls and focused bar. Use the displayed key hints when switching between spells, combat and action bars.

## Chat, emotes and resting

| Action                            | Default                               |
| --------------------------------- | ------------------------------------- |
| Open chat                         | Enter                                 |
| Open emote wheel                  | Hold T; release to dismiss            |
| Select emote                      | Click, Space or Enter                 |
| Cycle rest postures               | N                                     |
| Toggle chat-history interaction   | Ctrl+C outside text editors           |
| Temporarily interact with history | Hold Control; Command on macOS        |
| Page chat history                 | PageUp / PageDown when chat has focus |
| Cancel current action or context  | Escape                                |

[Resting](/holtburger/reference/3d-controls/#chat-emotes-and-resting) speeds health and stamina recovery. The cycle moves through kneeling, sitting, lying down and standing.

## Change bindings

Open **Settings → Input** for bindings, mouse steering and axis inversion. While typing or using a dialog, keys go to that control instead of the game.
