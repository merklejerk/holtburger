## Where to look

| Area                   | Includes                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| Graphics               | View distance, field of view, render scale, filtering, shadows, ambient occlusion and weather |
| Audio                  | Volume mix and mute preferences                                                               |
| UI                     | Themes, font choices, UI/text scaling, helper presentation and HUD placement reset            |
| Input                  | Keybindings, mouse movement and axis inversion                                                |
| Gameplay               | Gameplay preferences, including automatic key attempts                                        |
| Chat controls/settings | Destinations, message/channel filters, timestamps and message suppression                     |
| Launcher App settings  | Graphics backend and display synchronization before entering the game                         |

Use [interface layout](/holtburger/3d/interface/) to arrange the HUD, and [graphics help](/holtburger/support/graphics/) for tuning or startup trouble.

## General and character preferences

| Saved for this local installation    | Saved per character              |
| ------------------------------------ | -------------------------------- |
| HUD placement and overall appearance | Action-bar contents and loadouts |
| Keybindings and mouse preferences    | Spell bindings                   |
| Graphics and audio preferences       | Name-alert rules                 |
| Chat presentation and theme          | Combat controls                  |
| Spell-bar display shape              | —                                |

Changing an interface theme is different from changing a character's bars or alert rules. Preferences are local; there is no automatic cross-computer synchronization.

## Reset and update

Use **Reset HUD placements** when you want to restore the layout. For an individual binding, use the Input settings controls rather than editing files by hand.

Keep personal scripts and game data outside the application folder when updating. Older builds may not understand preferences introduced by newer builds, so avoid relying on a downgrade to preserve every newer setting.
